# Version 1.3: normalizar tablas de reportes

Esta versión es `V1.3__normalizar_nombres_tablas_nuevas.sql`. Renombra las
tablas de reportes, evidencia y polígono a los nombres que usan las entidades
JPA, redirige la bitácora a `reportes` y elimina las tablas heredadas vacías.

La migración requiere que `Registros`, `Fotos` y `Bitacora_Administrativa`
estén vacías. Verifica esa precondición y respalda la base antes de ejecutarla;
la eliminación de las tablas heredadas es irreversible si contienen datos.

Después de V1.3 se aplica V1.4, que crea la tabla de idempotencia y termina de
alinear el esquema con el backend actualizado.
